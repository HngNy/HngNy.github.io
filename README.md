# Cao Vũ Hằng Ny — Portfolio

Portfolio cá nhân của **Cao Vũ Hằng Ny** — Vận hành sàn TMĐT · Digital Marketing.

Live: https://hngny.github.io

Built with Next.js 15, MDX, Velite and shadcn/ui, statically exported and deployed to GitHub Pages.

## Development

```bash
corepack enable
yarn install
yarn dev
```

Xem hướng dẫn sửa nội dung chi tiết (tiếng Việt) trong [HUONG-DAN.md](HUONG-DAN.md).
