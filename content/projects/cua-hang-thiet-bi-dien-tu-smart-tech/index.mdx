## Overview

- **Type:** Course project — Banking University of Ho Chi Minh City
- **Role:** Requirements analysis, UI design, cart & checkout logic
- **Period:** 02/2024 – 05/2024
- **Stack:** Laravel, MySQL, HTML/CSS, PHP, Draw.io, Visual Studio Code

## What I did

- **Requirements analysis:** worked with stakeholders' needs to specify the system's functions.

- **Cart & checkout:** built the add-to-cart, cart update and checkout flow on the Laravel framework.

## Result

- Delivered a working online store with **sign-up, login, cart, checkout and order history**.

## What I learned

- How an online store stores and processes product and order data in a MySQL database.
